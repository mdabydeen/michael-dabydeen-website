# Review worksheet

Use this with the sample change or adapt it to a suitable, shareable example. It is a reasoning aid, not a safety certification or a numerical maturity score.

| Question | Your notes |
|---|---|
| What action could this change enable? | |
| What does the source contract actually guarantee? | |
| Which values or conditions does the change assume? | |
| Which revision and inputs does the evidence cover? | |
| Which meaningful cases have not been checked? | |
| What happens when a required fact is missing? | |
| What decision would you make now, and why? | |
| What evidence would change that decision? | |
| Who owns resolving an incomplete or disputed case? | |
| If an external effect has already happened, what remains to recover? | |

## Team discussion

Have participants record their decisions before comparing them. Discuss which differences come from missing evidence and which come from different policy choices. A defensible answer states its assumptions and limitations; agreement by itself does not establish correctness.

Choose one change to try in a real review process, identify its owner, and decide what observation would tell you whether it helped. Record a real follow-up rather than promising a percentage improvement in advance.
