This 2023 guide records the setup flow I used for a [Ledger](https://shop.ledger.com/) device, Ledger Live, and MetaMask. Hardware-wallet firmware, supported platforms, and extension screens change. Use the current vendor documentation as the source of truth before creating or moving assets.

## The rule that mattered

Keep the Ledger recovery phrase offline and private. Do not enter a Ledger recovery phrase into MetaMask, a website, a message, or a browser extension. Do not enter a MetaMask recovery phrase into a Ledger device.

The phrase controls the wallet. If someone obtains it, they can control the assets derived from it. A hardware wallet is only useful when the recovery phrase and signing action remain under the owner's control.

## Historical setup outline

The recorded sequence was:

1. Connect the Ledger device and follow its own screen to choose a language, create a PIN, and record the recovery phrase offline.
2. Download Ledger Live from the official Ledger site and connect the device through its current instructions.
3. Add only the accounts and networks required for the intended use.
4. Install MetaMask from its official download page if a browser interface is required.
5. In MetaMask, select the hardware-wallet connection flow and unlock the Ledger Ethereum account after opening the Ethereum application on the device.
6. Verify the receiving address and every signing request on the Ledger screen before confirming it.

MetaMask can display an account backed by a Ledger device. It does not receive the Ledger private key when the connection uses the hardware-wallet flow.

## Before using a current setup

Confirm the device is genuine, update it through the official application, and compare the instructions against [Ledger support](https://support.ledger.com/) and [MetaMask support](https://support.metamask.io/). Treat every recovery phrase, signature, and transaction as security-sensitive. This archived outline cannot validate a current wallet flow.
